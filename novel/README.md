# 📚 小说项目（穿越类）

> 本目录位于 F 盘，所有 skill 和作品文件都在这里，不占用 C 盘空间。

## 怎么用

在 ZCode 中把工作目录切换到本文件夹（`F:\novel`），即可自动加载三个写作 skill：

| Skill | 触发场景 | 产出文件 |
|---|---|---|
| `/novel-setup` | 开新书：灵感、世界观、人物、金手指 | `设定.md` |
| `/novel-outline` | 要大纲、分卷、章节规划 | `大纲.md` |
| `/novel-writing` | 写章节、继续写、润色修改 | `正文\第00X章-*.md` |

也可以不输入斜杠命令，直接用自然语言说"帮我设定一个穿越到宋朝的小说"就会自动触发。

## 目录结构

```
F:\novel\
├── README.md              ← 本文件
├── .zcode\skills\         ← 三个写作 skill（novel-setup / novel-outline / novel-writing）
├── 资料\                   ← 写作参考资料（如《三国基础资料.md》：时间线/人物/地理/官职）
├── 设定.md                 ← 世界观、人物、金手指（开书第一步）
├── 大纲.md                 ← 分卷 + 章节计划
└── 正文\                   ← 章节正文，每章一个文件
```

## 写作流程建议

1. **novel-setup**：说灵感 → 生成设定 → 确认
2. **novel-outline**：生成大纲 → 调整 → 确认
3. **novel-writing**：一章一章写，随时可润色

💡 想重开一本书？把 `设定.md`、`大纲.md` 删掉（或移进 `存档\`），再走一遍流程即可。

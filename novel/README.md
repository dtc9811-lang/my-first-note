# 《华初》项目索引

这是“任道远，字行之”架空三国长篇项目。主线从183年湘南县仓疑账开始，经历汉末起兵、三国争霸、架空一统、开国治理与晚年纠偏，写到252年任道远去世。

## 当前核心文档

- `主角大纲.md`：任道远166—252年的完整十阶段人生与全书主线。
- `设定.md`：作品定位、人物群像、官制、冬学、清簿、大作与储位等设定。
- `第一卷大纲.md`：183—189年“青梓之火”，48章。
- `第二卷大纲.md`：189—191年“骑田风雷”，45章。
- `程恪人物大纲.md`：终身副手程恪的思想成长、关系结构和晚年责任。
- `资料/任道远写作一致性核对表.md`：年龄、官制、战争、粮草与因果自检。
- `资料/毛选思想成长分析.md`、`资料/毛选情境伴读/`：思想原型研究资料，不直接作为小说事件模板。

## 已定创作原则

1. 任道远是汉末土生土长人物，不使用穿越或预知历史设定。
2. 现实参照只保留思考方法、关系结构与权力难题，不逐项换名复刻生平。
3. 所有冲突从汉末土地、宗族、坞堡、察举、军功、粮运和法统自然生长。
4. 主角可以犯严重错误；错误必须在当时有合理来源，也必须留下具体伤亡与制度后果。
5. 大一统是全书中段成果，不是终点。后半部重点写国家怎样获得纠错能力，普通编户怎样从识字、查账和有限议事开始掌握政治权利。

# 《毛泽东选集》情境伴读

> 目的：先把文章放回它写成的那一天，再进入原文。这里不替任何政治结论背书，也不要求读者先接受一种评价；它只努力回答：毛泽东当时身在何处、拥有多大权力、面对谁、知道什么、担心什么、为什么提出这个办法，以及事后发生了什么。

## 一、为什么直接读《毛选》容易读不下去

《毛选》不是按“毛泽东从年轻到晚年的完整传记”编的，也不是未经整理的日记。第一至四卷收录的是1925—1949年间被认为最能说明革命道路的文章、报告、决议、电报和讲话，建国后又经过选择、校订和文字修订。因此，读者很容易遇到三种错觉：

1. **把事后的领袖地位倒推回当时。**1927年的毛泽东不是后来那个可以最后拍板的人；1929年古田会议前，他甚至刚在红四军党内选举中失去前委书记职务；1935年遵义会议也不是一夜之间把全部党权、军权交给他。
2. **把文章当成抽象哲学。**许多名篇原本是在回答具体争论：《星星之火，可以燎原》是写给悲观而主张流动作战的林彪的信；《论持久战》同时反驳亡国论和速胜论；《党委会的工作方法》写于即将接管全国之际。
3. **把编辑后的理论完整性当成原始思想过程。**收入《毛选》的文字有时比初版更整齐、更符合后来形成的理论体系。研究“当时怎么想”，必须把写作时文本、后来定本和事后结果分开。

## 二、每篇文章只追问七件事

打开原文前，先读本伴读中相应的“情境卡”，然后带着七个问题阅读：

1. **他当时是什么身份？**边缘干部、根据地领导、军事决策成员，还是最高领袖？
2. **眼前危机是什么？**组织会被消灭、同盟将破裂、军队缺粮，还是胜利过快导致政策失控？
3. **他要说服谁？**中央、军队干部、党内同事、统一战线伙伴、知识分子，还是全国公众？
4. **真正争论的方案有哪些？**不要只记文章批判了谁，要恢复对方当时为何觉得自己的办法合理。
5. **他用了什么证据？**调查、军事经验、阶级分类、国际局势、组织纪律，还是历史类比？
6. **决策链是什么？**他怎样从事实判断走到行动方案，中间有没有跳步？
7. **后来怎样？**哪些判断被验证，哪些条件改变，哪些副作用当时尚未看见？

读完后用一句话复述：

> 因为当时出现了____，多数人主张____；毛泽东根据____判断真正要紧的是____，所以提出____，并准备承担____风险。

如果能够填完这句话，就已经读懂了文章的骨架，不必先背名句。

## 三、建议的最短路线：先读十八篇

不要从第一卷第一页一路硬啃。下列顺序能先搭起他的思维骨架，再回头补全文。

| 顺序 | 文章 | 先看什么 | 读完应明白什么 |
|---|---|---|---|
| 1 | 《湖南农民运动考察报告》 | 国共合作正在破裂，农民“过火”成为党内外争议 | 他为什么相信被精英视为混乱的人群具有政治主体性 |
| 2 | 《中国的红色政权为什么能够存在？》 | 城市起义失败，小块山区政权看似没有前途 | 他怎样从中国的不统一中寻找弱者生存的结构条件 |
| 3 | 《关于纠正党内的错误思想》 | 红军是旧军人、农民、俘虏和地方武装的混合体 | 军队怎样从打仗集团变成政治组织 |
| 4 | 《星星之火，可以燎原》 | 红军屡败、有人悲观，主张四处流动 | 战略乐观不是喊必胜，而是分析力量怎样随时间变化 |
| 5 | 《反对本本主义》 | 上级指示、苏联经验与地方事实冲突 | 调查为何是路线形成过程，而不只是工作作风 |
| 6 | 《关心群众生活，注意工作方法》 | 根据地被围剿，财政和民生同时吃紧 | 群众支持如何由盐粮、借贷、住房和办事方式产生 |
| 7 | 《论反对日本帝国主义的策略》 | 长征刚结束，日本压力改变国内力量关系 | 目标不变时，敌友范围为什么必须随主要矛盾改变 |
| 8 | 《中国革命战争的战略问题》 | 第五次反“围剿”和长征的惨痛经验尚近 | 总体弱势者怎样通过退却、集中和选择战场获得主动 |
| 9 | 《实践论》 | 需要从哲学上解释照搬理论为何失败 | 认识怎样从行动中来，又必须回到行动接受检验 |
| 10 | 《矛盾论》 | 全国矛盾、党内争论和战争阶段同时变化 | 为什么不能用一个公式处理所有时间、地区和对象 |
| 11 | 《论持久战》 | 日军连续攻城，中国同时流行亡国论与速胜论 | 怎样把时间、空间、民众和国际环境变成力量变量 |
| 12 | 《新民主主义论》 | 中共需要回答抗战胜利后建什么国家 | 他怎样设计一个分阶段、多阶级联合的过渡国家 |
| 13 | 《改造我们的学习》 | 延安干部来源复杂，王明路线与本土经验冲突 | 调查研究如何进入组织的知识生产和权力结构 |
| 14 | 《关于领导方法的若干问题》 | 组织迅速扩大，中央不可能直接了解每个基层 | “从群众中来，到群众中去”具体是怎样的信息循环 |
| 15 | 《论联合政府》 | 抗战将胜，中共已成为全国性政治力量 | 从根据地治理走向全国政权时准备联合谁、保留什么 |
| 16 | 《抗日战争胜利后的时局和我们的方针》 | 日本突然投降，国共争夺受降、交通线和城市 | 为什么一边准备谈判，一边判断内战危险仍在 |
| 17 | 《目前形势和我们的任务》 | 战局开始逆转，土地改革出现扩大化风险 | 从防御转进攻时怎样同步调整军事、土地与工商政策 |
| 18 | 《在七届二中全会上的报告》＋《党委会的工作方法》 | 全国胜利在即，干部将从乡村进入城市执政 | 他怎样预见胜利者腐化，以及怎样设想集体领导方法 |

建议节奏：每天只读一张情境卡和原文的一个小节。较长的《论持久战》《新民主主义论》《论联合政府》拆成三天，不追求一次读完。

## 四、三份正文怎样使用

- [第一册：从发现农民到形成全国战略](./第一册-1925—1937.md)：1925—1937。重点是农民、根据地、建军、调查和遵义会议后的战略上升。
- [第二册：抗日战争中的时间、联盟与组织](./第二册-1937—1945.md)：1937—1945。重点是持久战、统一战线、新民主主义、延安整风、群众路线和经济工作。
- [第三册：从谈判、内战到接管全国](./第三册-1945—1949.md)：1945—1949。重点是重庆谈判、东北、集中兵力、土地政策纠偏、三大战役和进城执政。

每册都把文章分为三档：

- **A档：必须精读。**构成思想转折点。
- **B档：带着问题选读。**补足政策和组织细节。
- **C档：查用。**多是时评、电报、声明或同一阶段判断的重复展开，不必第一次就读完。

## 五、先记住这张“权力位置表”

| 时期 | 毛泽东的大致位置 | 不能倒推的误解 |
|---|---|---|
| 1925—1927 | 国共合作体系内从事宣传和农运的中共干部，在党内不是最高决策者 | 不能把他的农民主张理解成当时全党既定路线 |
| 1927—1928 | 秋收起义和井冈山根据地领导者，受中央和湖南省委多重指示约束 | 不能把进入山区写成一开始就被普遍接受的成熟道路 |
| 1929—1931 | 红四军主要领导之一，与朱德、陈毅及中央之间存在真实争论 | 古田会议决议不是一人向所有人训话，而是争论、离职、中央协调后的结果 |
| 1931—1934 | 中华苏维埃共和国中央政府主席，但在中央军事路线上的影响一度被削弱 | 有国家主席名义，不等于掌握第五次反“围剿”的最后军事决策 |
| 1935—1936 | 遵义会议后进入军事决策核心，与张闻天、周恩来、王稼祥等共同工作 | 遵义不是立即获得后来意义上的党主席全部权力 |
| 1937—1938 | 中央主要领导和军事战略权威，但王明回国、共产国际意见、国共合作均构成约束 | 抗战路线仍经历党内争论与权力重组 |
| 1939—1942 | 全国理论方案的主要提出者，逐步取得党内思想领导权 | “毛泽东思想”尚在形成，组织统一不是天然存在 |
| 1943—1945 | 中央最高领导地位制度化，七大形成以毛为核心的领导格局 | 此时的文章已兼具分析问题和规范全党语言的双重作用 |
| 1945—1949 | 全国性革命和战争的最高战略领导者，在中央书记处集体中决策 | 即便权威很高，军事、土地、城市和外交政策仍由庞大组织共同形成、执行和反馈 |

## 六、核心人物关系不要读成简单派系表

| 人物 | 关系的主要阶段 | 伴读时应注意 |
|---|---|---|
| 朱德 | 井冈山会师后的军事搭档；1929年围绕前委、军权与党内制度发生争论；后来长期合作 | 分歧真实，不能抹掉；合作同样真实，不能倒写成终身私怨 |
| 陈毅 | 红四军争论中的协调者，赴上海向中央报告并参与形成“九月来信” | 古田会议结果包含陈毅、周恩来和中央的作用 |
| 周恩来 | 早期中央领导；遵义后与毛、王稼祥组成军事领导小组；此后长期处于核心协作关系 | 很多决定是分工与集体形成，不宜全归于一人预见 |
| 张闻天 | 遵义前后支持军事路线调整，随后长期主持中央日常工作 | 毛的领导形成经过与张闻天合作，而不是只靠击败对手 |
| 王稼祥 | 遵义会议及其后的重要支持者和军事领导小组成员 | 是领导联盟形成的关键节点 |
| 博古 | 1931—1935中央主要负责人之一，遵义后仍从事中央工作 | 路线失败不等于人物此后从组织中消失 |
| 李德 | 共产国际派来的军事顾问，与博古、周恩来组成原军事指挥核心 | 其方案也来自正规战、保卫中央苏区等压力，不能只当无知外人 |
| 王明 | 共产国际背景深厚，1937年回国后主张更强调统一战线与国民党合作 | 延安整风既有理论路线之争，也改变了党内权力与历史叙述 |
| 刘少奇 | 白区工作和组织建设领导者，延安时期进入核心，解放战争中负责土地与华北工作 | 前四卷时期主要是合作和分工，不能把后来决裂提前投射进去 |
| 彭德怀 | 红军和八路军重要将领，军事意见并非总与毛一致 | 分歧须按当时战场与权限看，不宜用1959年倒解释此前一切 |
| 蒋介石 | 从国共合作阵营领导人，变为清共与围剿的主要对手；抗战中又成为必须合作而防范的盟友；战后再度决战 | 是理解“敌友随阶段重排”最重要的关系 |

## 七、资料边界和可信度标记

本伴读使用三类材料，并在有争议处标记：

- **A：原始或接近原始材料。**文章原文、同期中央文件、书信、电报、会议记录、早期版本。
- **B：机构性整理。**中央党史和文献研究机构、大事记、正式年谱与专题史。优点是材料系统，缺点是倾向把争论整理成清晰的正确路线发展史。
- **C：研究者与回忆材料。**用于补足现场、版本差异和权力关系。必须核对作者立场、成书时间和是否能由同期材料互证。

遇到“某人当时心里真正怎么想”而没有日记、信件或同期记录时，本文只写“从其行动可以推断”“后来的回忆称”，不把推断写成事实。

## 八、版本提醒

1. 第一至四卷是胜利后形成的经典文本，适合学习其成熟表达，不等同于原始手稿全集。
2. 《中国社会各阶级的分析》《星星之火，可以燎原》《中国革命和中国共产党》等存在值得注意的初版、未删节本或后期增修。
3. 《实践论》《矛盾论》来自1937年抗大哲学讲授提纲的一部分，不能仅当作书斋论文。
4. 第五卷由1977年出版，选文、整理和版本问题与前四卷不同；1958—1976更不能只靠第五卷理解，须另建晚年史料册。
